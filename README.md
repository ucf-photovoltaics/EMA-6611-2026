# EMA 6611 – Optoelectronics Materials Processing (Fall 2026)

Colab homework assignments for EMA 6611 at the University of Central Florida, taught by Prof. Kristopher O. Davis. Assignments are posted here one at a time under `homework/` as they are assigned; everything else for the course (syllabus, problem sets, report template, submission) lives on Webcourses.

## How to open an assignment in Google Colab

1. Go to [colab.research.google.com](https://colab.research.google.com/) and choose **File → Open notebook**.
2. Select the **GitHub** tab and paste this repository's URL: `https://github.com/ucf-photovoltaics/EMA-6611-2026`
3. Pick the assignment notebook (e.g., `homework/HW01/EMA-6611-HW01.ipynb`).
4. **Immediately choose File → Save a copy in Drive** — the GitHub copy is read-only, and work done without saving a copy will be lost.

Each assignment ends with a submission checklist. In short: restart and run all, then submit the **printed PDF** of the completed notebook (File → Print → Save as PDF), the **.ipynb** file (File → Download), and any required data files on Webcourses.
